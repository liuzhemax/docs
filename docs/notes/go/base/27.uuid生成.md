运行这个程序，它会生成一个随机的UUID并打印出来。

注意：UUID（通用唯一识别码）是一个128位长的数字，通常用于软件开发中确保每个标识符的唯一性。

```go
package main

import (
    "fmt"

    "github.com/google/uuid"
)

func main() {
    // 生成一个UUID
    uuidObj, err := uuid.NewUUID()
    if err != nil {
        fmt.Println("生成UUID失败:", err)
        return
    }

    // 打印UUID
    fmt.Println("生成的UUID:", uuidObj.String())
}

// 尝试把生成UUID包装成一个函数，然后在Main主函数里面调用并输出字符串的uuid值。
```
