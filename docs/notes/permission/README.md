::: tip
权限管理平台，基于JWT技术实现前后端分离，基于角色访问控制RBAC，提供对系统的权限控制。
:::

### 功能特性
 - 个人中心: 资料查看，密码设置
 - 用户管理: 增删改查，角色授权
 - 角色管理: 增删改查，权限分配
 - 菜单管理: 增删改查
 - 免费开源: 前后端代码完全开源, 方便二次开发

### 技术栈
 - Python 3.11
 - Djnago DRF 5.1
 - Vue 3
 - Element Plus
 - MySQL 8.0
